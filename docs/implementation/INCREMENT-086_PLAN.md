## Gap / dependency
S101.3 has an append-only SQLite effect manual review table/method, but there is no native-only renderer action that lets an operator record a reason/disposition against one unresolved effect after crash/restart. Current manual-review writer requires at least one evidence reference even for the explicit `PROVIDER_EVIDENCE_MISSING + AWAITING_EVIDENCE` case, so it cannot faithfully record the absence of evidence. The review must remain an audit note only: it cannot confirm an effect, clear uncertainty, resolve a job, retry PUBLISH/COMMENT or authorize cleanup.

- Evidence absent is recorded explicitly with empty refs only for `PROVIDER_EVIDENCE_MISSING/AWAITING_EVIDENCE`; no fake evidence ID or placeholder receipt.
