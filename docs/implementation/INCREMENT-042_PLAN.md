## Scope and safeguards

S095 requires transfer/index/MediaStore on Android, which is not certified. Build the first real host-only prerequisite, **not** a pretend Android stage:

1. Add `HostStagingLedger` under `packages/media/src/staging.ts`. The staging directory is a private subdirectory of the existing app data root, never a user-selected source root. Ensure private directory ownership, reject symlink roots, and limit stage to a bounded set of immutable `JobMediaPreflightPlan` entries (max32 files,4GiB/file,8GiB total). Check available space with a safety reserve. File names are generated by ordinal and allowlisted media extension; no path, caption or hardware ID from the user reaches path joining.
2. Atomic job-unique staging: exclusive per-job lock and a fresh private pending directory; for each approved host media grant canonicalize source, open without following symlink where supported, stream bytes into app-owned `wx` files, check pinned size/SHA-256, source identity/mtime/canonical path after read, fsync file; write bounded manifest with owner hostId/jobId/revision/snapshot hash, ordered entries and digest, sync it; rename pending directory into the final job namespace. Never overwrite an existing staged namespace or delete an unknown folder. Only remove a pending directory created by the active operation; a crash may leave an orphan for future explicit reconciliation.
3. Existing namespace may be reused **only after** manifest ownership/digest/entry-order and all staged file bytes are revalidated, using no untrusted manifest path traversal or symlinks. Mismatch fails closed rather than overwriting/deleting.
4. Integrate `HostMediaService.stageJobHostMedia(jobId)` as an internal-only service call using the private DB `job.mediaPlan`, with after-copy plan recheck. Supply the app-owned data directory from Electron main and loopback host. No new public `StudioApi`, preload command or device input. No automatic staging on schedule, scan or startup. Return redacted `HOST_STAGED_NOT_ANDROID` result with `canDispatch:false`; never call a host file copy an Android MediaStore index.
5. Unit/host integration with real temp files: ordered two assets, hash/bytes verified, exact manifest; replay idempotent and tampering detected; changed source and wrong host rejected, no deletion of source data; corrupt/foreign manifest and symlink roots rejected; no claim/effect/ADB call; text-only report does not stage an empty namespace. Cross-platform Windows/Linux safety and no package/lock migration regression.
6. After source commit run Ubuntu and Windows `pnpm check`, Chromium UI and plan validators. Fix failures, document exact source SHA and CI/test counts. Keep `main`/installer unchanged. **No Android transfer, publish or full S095 gate claim** until physical device/MediaStore evidence.
