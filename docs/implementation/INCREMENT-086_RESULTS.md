Only the **self-declared** actor ID is shown; no effect/request IDs, evidence reference values, idempotency keys or hashes. The UI explicitly states that the actor identity and evidence content are not authenticated by this note.

It cannot confirm provider success, change job/effect state, retry or dispatch.
- `apps/desktop/src/main/index.ts` and `apps/desktop/src/preload.cts`: dedicated `studio:effect-manual-review` IPC, strict sender/main-frame/allowed URL and Zod schema; separate native preload bridge, no public StudioApi/loopback operation.

Empty refs allowed only for “missing provider evidence / awaiting evidence”. Persisted note count/latest history is shown after refresh; a maximum of 32 notes is enforced by UI and DB. All confirmations/retries/dispatch rights remain false.
