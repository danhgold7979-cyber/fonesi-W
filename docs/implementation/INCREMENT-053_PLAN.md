## Why this increment exists
The v19 journal records job/stage/device/host/generation/nonce/remote path, while ADB SEND, RECV and MediaStore independently construct remote names. No unified checked invariant currently prevents future cleanup from targeting a tampered remote path. The operator's redacted page only reads persisted observations and cannot authorize deletion. Before implementing a destructive Android action, make owned-path identity and current-lease/effect/evidence predicates testable and fail-closed across DB + device adapter + trusted host.
