# Increment021 — P02/S020, P13/S116–S117 workspace health + verified local backup

Plan trước code. Baseline020:215 unit/integration +20 browser. Là lát vận hành độc lập, chưa đóng full P13.

1. Add named workspaceStatus/createWorkspaceBackup. Public chỉ backupId whitelist (backup_+32hex), không paths/SQL/host ID. Status DTO allowlist: platform/arch/runtime version/host memory, actual filesystem capacity/available, SQLite quick check/schema/aggregate table counts/unresolved effects. Không đọc/export content values, account names/source paths/serials/env. Missing disk data có unavailable reason, không gán0 thành số đo thật.
2. DB metadata trong serialized worker; consistent read transaction và PRAGMA quick_check. Full backup SQLite online API -> private read-only integrity/schema/migration checksum validation. Worker phải await async internal call trước postMessage/nhận lệnh tiếp theo. Hash/size file nằm ngoài worker.
3. App-owned canonical backup directory, reject symlink escapes. One backup at a time; reserve >= DB+WAL size +64MiB available trước copy. Unique staging path, atomic no-replace link to requested ID, receipt file with exclusive create. Không overwrite live DB/prior backup. Chỉ xóa positively owned partial temp; không auto delete completed backups hoặc user media.
4. Completed receipt gồm ID/time/size/hash/schema/integrity, không secret values. Retry ID qua restart verify existing file+receipt và trả alreadyCreated; final file chưa có receipt do crash có thể recover sau integrity/hash. Changed/corrupt/symlink backup bị reject, không tự tạo đè. Host close ngừng nhận mới, đợi backup/abort fingerprint trước DB close.
5. Compact header button mở dialog health/backup; loading/error/retry, disk unavailable và observed counts rõ. Save ACK của editor/Process trước backup để chứa thay đổi đang soạn. Backup mô tả rõ chỉ DB, không source media; full DB có dữ liệu riêng tư, không tự gửi đi. Diagnostic JSON download riêng từ allowlisted status đã xem, do user click; không tải DB qua HTTP/clipboard hoặc gửi bên ngoài.
6. Actual FS/SQLite worker tests: backup consistency/durable fields/schema/integrity/hash, reopen/retry, crash receipt recovery, corrupt/low disk/concurrency/shutdown/symlink/path rejection. Browser thật kiểm status, saved data trước backup và sanitized local JSON download. Electron/main wiring dùng cùng service; Windows smoke riêng.

Deferred: restore UI/quiesce, retention/structured run logs, tray/power hooks, low-disk staging enforcement, APK/network providers và hardware scale acceptance. Không claim các phần deferred là xong chỉ vì health panel đã có.
